# 新希望投资调研文档

> 标的：新希望（000876）｜研究快照：2026-11-07｜最新完整月：2026-10

## 1. 结论

**采用严格甲方案：当前月度PB未进入主规则低位区间，暂不启动定投，继续等待。** 不因预期猪周期反转而提前入场，也不临时改用更有利的统计窗口。

## 2. 为什么关注

- 生猪价格处于历史低位，能繁母猪存栏已有下降，提供周期修复的观察依据。
- 新希望PB处于历史偏低位置，值得跟踪，但“偏低”不等于已满足本轮买入条件。
- 投资逻辑是等待“周期修复机会＋足够低的估值”同时出现。周期何时反转尚未确定，公司能生存也不等于股东能赚钱。

## 3. 本轮投资策略

### 方法依据

借用《指数基金投资指南》的**博格公式变种**，以周期行业的市净率观察估值：

\[
股价=每股净资产\times PB
\]

股价回报取决于每股净资产变化与PB变化的共同作用，另有分红。**净资产缩水可能抵消PB回升，不能只押估值修复。**

### 买入、持有、卖出区间

主规则采用近十年**月度PB历史时间分位**，暂以Q20、Q80划分。以下用本轮原始阈值，约数分别为1.66和2.84：

| 月度PB | 本轮策略 |
|---|---|
| 低于 **1.659** | 进入低估区；复核经营、净资产与偿债风险后，考虑启动定投 |
| **1.659～2.842**（含边界） | 持有观察，不新增定投；未建仓则继续等待 |
| 高于 **2.842** | 进入高估区及卖出阶段；具体卖出方式不在本文展开 |

Q20/Q80是本轮研究约定，**不是书中固定买卖线、内在价值或盈利概率，也不是自动下单指令**。跨度位置、近五年窗口仅辅助，不用于放宽主规则。

## 4. PB数据

**口径：**通过AKTools获取百度近十年PB，共731个每隔5自然日的采样点；取2016-12至2026-10的119个完整月，每月计算采样PB中位数，再计算月度历史分位。不是全部交易日中位数；未完成的11月不纳入。

| 指标 | 数值 |
|---|---:|
| Q10 | 1.485 |
| Q20：低位分界 | 1.659 |
| Q50：历史中位数 | 2.025 |
| Q80：高位分界 | 2.842 |
| Q90 | 3.553 |
| 2026年10月PB中位数 | **1.875** |
| 该月历史时间分位 | **35.3%** |

时间分位表示历史月度样本中不高于该值的比例，**不代表上涨概率**。当前未进入最低20%区间，因此等待。

辅助检查：该月在Q10—Q90跨度中的位置约18.9%，但这不是时间分位；近60个月时间分位约18.3%，说明结论存在窗口敏感性，而非多个窗口一致低估。保留真实周期高低点，不为得到买入结论删去极值。

**来源核对：**本次新希望样本中，东方财富原始历史PB存在提前使用尚未公告财报分母的现象，不直接用于模拟当时决策。按公告日期分母重建核对后，上述十年月度统计基本不变；但首次披露版本、公告时点及少数市值差异尚未全部核清，不视为完整时点审计。

## 5. 后续怎么做

1. 每个完整月结束后，按同一来源、频率与月度中位数口径复核PB；不拿单日PB替代月度信号。
2. 未触及低位条件，继续等待；触及后先检查最新已披露财报、普通股净资产及偿债融资，再决定是否启动。
3. 如已持仓，按上述区间区分持有与卖出；重大经营恶化时单独重审，不机械等到高估区。
4. 当前阈值是研究快照。更新样本或改变规则时记录依据，不为迎合买入意愿临时切换窗口；财报未披露不提前切换净资产分母。

## 6. 关键风险

- **周期风险：**产能去化不保证猪价很快反转，低价可能持续，公司盈利改善还取决于成本。
- **净资产与适用性：**亏损、减值会侵蚀净资产；公司历史亏损也不满足原书“最差盈利阶段仍不亏损”的保守前提，此处只是借用估值框架。
- **融资与摊薄：**现金流、债务到期及再融资可能改变投资逻辑；增发可能摊薄每股净资产，不能将PB变化全部解释成股价变化。
- **统计局限：**采样、窗口和财报生效时点会影响PB判断；历史低估不等于未来高收益。
