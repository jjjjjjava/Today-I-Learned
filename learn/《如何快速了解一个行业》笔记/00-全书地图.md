# 《如何快速了解一个行业》全书地图

## 本书告诉我们什么：解决什么问题

**给你一个行业，你怎么知道它现在是什么状态，未来会怎样发展？** 先判断行业处于哪个阶段，再看这个阶段最关键的问题。

| 行业阶段 | 研究重点 |
|---|---|
| 导入期 | 生意做得成吗？有人愿意付钱，企业能靠它赚钱吗？ |
| 成长期 | 市场究竟有多大？离饱和还有多远？ |
| 成熟期 | 生意守得住吗？利润在同行和产业链上下游之间怎么分？ |
| 衰退期 | 谁在替代它？客户转向了哪里？ |

## 全书地图

### 第一部分　行研框架篇

| 章 | 关键词 | 这一章回答什么？ |
|---|---|---|
| 1 | 主框架 | 行业处在哪个阶段？这个阶段应该重点看什么？ |
| 2 | 可行性：商业模式 | 生意做得成吗？有人买，企业也有可能赚钱吗？ |
| 3 | 规模性：市场规模 | 这个市场到底有多大？离饱和还有多远？ |
| 4 | 防守性：护城河 | 这门生意守得住吗？什么让它不容易被替代？ |
| 5 | 盈利性：竞争格局 | 利润归谁？横向看同行怎么竞争，纵向看上下游怎么分利润。 |
| 6 | 估值 | 行业处在不同阶段，投资者该怎样给其中的公司估价？ |
| 7 | 外部因素 | 政策、经济、文化或技术发生什么变化，会改变原来的判断？ |
| 8 | 景气度 | 跟踪哪些指标，能提前判断行业业绩增速在加快还是放缓？ |
