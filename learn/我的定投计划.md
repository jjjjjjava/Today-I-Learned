## 2. 挑选好基金

**标准（原书第4章，见 [03-估值与选基](03-估值与选基.md)）：只在"价格低于价值"时买。**

| 标的类型 | 用什么判断 | 当前清单 |
|---|---|---|
| 盈利稳定的宽基指数 | 盈利收益率 $>\max(10\%,\,2\times\text{无风险利率})$ 买入；$<6.4\%$ 分批卖出 | 待选（尚无已确认标的） |
| 成长指数 | PE 在自己历史区间的位置 | 待选 |
| 周期指数 | PB 在自己历史区间的位置（前提：最差时不亏损） | 待选 |
| **单只周期股：隆基绿能（601012）** | **月度PB低位 + 每月复核核心假设**，不是原书原样规则 | **已确认，见** [隆基绿能投资调研文档 §1–§3](隆基绿能投资调研文档.md) |

**隆基的选择理由、PB数据、净资产下降情况、保守情景测算**，全部见隆基文档 §2–§3.4，本文不重复。关键结论一句话：

> 本轮赚的是**低PB的估值修复**；隆基当前亏损，**不满足原书"最差盈利阶段仍不亏损"的前提**，是改编应用，不是照搬已验证规则。

**指数基金部分**尚无已确认标的；有了再按上表补一行，并链到对应的笔记或调研文档。

## 4. 每月审阅清单（每次投资前打开本节）

> 用法：每月执行日前一天，**复制本节到当月记录**，逐项勾选。有任何一项是"否"，**本月不买**。不在行情急跌或急涨的当天修改规则，规则只在"复盘日"改。

### 4.1 钱是否可以动

- [ ] 本月可定投总额已确认，且**备用金完整**。
- [ ] 隆基累计已投入 ____ 元，剩余预算 ____ 元（总预算150,000）。
- [ ] 近3年内没有新增的确定大额支出，投入的钱仍是"3年以上不用"的钱。

### 4.2 隆基：信号与金额

- [ ] 取上一完整月（____ 年 ____ 月）的**月度PB**：____（同源同口径；若PB非正或数据异常，先暂停核实）。
- [ ] 月度PB是否 $<2.251$：是 / 否（否则本月不买，转持仓复核）。
- [ ] $PB_0$ = ____（首投当月锁定，之后不改）。
- [ ] 计划金额 $=\min(17500\times PB_0/PB_t,\;35000,\;\text{剩余预算})$ = ____ 元。
- [ ] 记录执行日单日PB ____，与信号PB相差 ____ %（只记录，不用来替代信号）。

### 4.3 隆基：五项检查（任一项重大疑点未解 → 暂停）

最新已披露财报：____ 年 ____ 季报。没有新财报时，沿用上一份，**并查本月新公告与行业变化**，不把"没有新财报"当通过。

- [ ] **净资产与资产质量：**普通股每股净资产 ____ 元；**低于约5.49元一律暂停**；下降原因已拆清（经营亏损／减值／其他权益变动）。
- [ ] **盈利恢复能力：**出货增长之外，完整单位利润是否在改善：____。
- [ ] **相对竞争力：**与同行（晶科、爱旭）毛利、扣非利润比较，是否持续掉队：____。
- [ ] **现金与偿债：**经营现金流、短期债务、资本开支、融资压力有无明显恶化：____。
- [ ] **估值修复空间：**用最新净资产与盈利判断，原来的逻辑是否仍成立：____。

结论（三选一）：
- 逻辑成立且条件满足 → 按4.2的金额买入。
- 有重大疑点、判断不清 → **暂停本月**，不自动补投，写下要查的问题。
- 确认价值基础或竞争力受损 → 重估、减仓或退出，另行决定。
