# 04 社会认知：事实一个，解释很多

> 《亲密关系》第 8 版第 4 章。原书按「第一印象 → 知觉的力量 → 印象管理 → 我们到底有多了解伴侣」推进。

问题：
同一件事，为什么我看到的和她看到的不是同一件？我的判断从哪里来，又怎样反过来改变关系？

## 一句话主线

**判断 → 感受 → 行动 → 关系。** 判断错了不致命，**不知道自己在这一步加了推测**才致命。

开篇的例子：我生病卧床一整天，爱人没打一个电话。可以读成「她不体贴」，也可以读成「她不想吵醒我」。事实只有一个，解释有好几种，而解释决定我接下来是冷淡还是照常。

## 四块一图

| 块                | 它回答什么                       |
| ---------------- | --------------------------- |
| **第一印象**         | 初次几秒的判断从哪来，为什么改不掉            |
| **知觉的力量**       | 判断形成后，怎样改变我对伴侣的感受和关系        |
| **印象管理**        | 我怎样影响对方对我的看法                |
| **有多了解**        | 这些判断究竟准不准                   |

## 一、第一印象：一条四步链

| 机制         | 它在做什么                        |
| ---------- | ---------------------------- |
| **刻板印象**   | 把人归入类别；它是**归类的工具**，不是判断的对象   |
| **首因效应**   | 最先得到的信息权重过大，并决定我怎样解释后来的信息   |
| **验证性偏差**  | 只找能证实自己的问题；拿到的必然是片面证据       |
| **过度自信**   | 从没遇到反例，于是确信自己比实际更准          |

初判只要 39 毫秒就能形成「这张脸是否在生气」；十分之一秒足够判断吸引力、讨喜与可信度，而结果和细看一分钟几乎一样。**速度快不是问题，问题在于后面每一步都在加固第一步。**

**哈娜实验（Darley & Gross, 1983）：** 两组人先看到同一个女孩的「穷」或「富」的生活录像，再一起看**同一段**测验录像。两组最初对她成绩的猜测一样；但看完录像后，认为她穷的人挑出她的错误、判她低于平均，认为她富的人挑出她的成功、判她高于平均。**偏差不在观察，在解释。** 两组都认为自己公平，都没意识到另一组看了同样的录像。

## 二、知觉的力量

### 伴侣的理想化：善意解释，不等于编造

**积极错觉**＝在了解全部事实的前提下，把缺点看成局部的瑕疵。这和「凭空虚构伴侣没有的优点」是两件事，分界线是**有没有事实打底**：有，关系更满意、伴侣自尊更高；没有，幻想必破。

另一半动作是**校准期望**：相处越久，越会把「理想伴侣」的标准修正成「眼前这个人的样子」——让对方不变，只动期望那一端，落差才会缩小。

### 归因：把「谁的错」拆成三个问题

| 维度          | 它在问            | 它决定什么          |
| ----------- | -------------- | -------------- |
| 内部 / 外部     | 是他这个人，还是他遇到的事？ | 要不要当成性格问题      |
| 稳定 / 易变     | 以后还会不会这样？      | 要不要长期应对        |
| 可控 / 不可控    | 能不能改？          | 该沟通，还是接受       |

同一个「他迟到」：内部 + 稳定 + 可控（一贯不守时，说了能改）→ 值得谈；外部 + 易变 + 不可控（地铁故障）→ 不值得计较。**只问「谁的错」停在第一维，会漏掉会不会再发生、我能不能处理。**

**三种模式：**

1. **行动者 / 观察者效应。** 我清楚自己的处境压力，却把对方同样的行为归因成性格。争吵中一方想「她那样做激怒了我」，另一方想「他太喜怒无常」。最保险的假设是：即使最亲密的伴侣，也很少知道你行为的所有原因。
2. **自我服务偏差。** 成功归自己，失败找外因。根源是信息不对称：我掌握自己的意图，别人只掌握我的行为。「我打算给她做早餐」和「他睡过头直接走了」，在两个人眼里是两个故事。
3. **增进关系 / 维持痛苦。** 满意的人把好事归为**内部 + 稳定 + 可控**（她本来就这样），把坏事归为**外部 + 易变 + 不可控**（偶尔一次）；不满意的人正好相反——**善意视为偶然，伤害视为蓄意**，于是再多的示好也换不到满足。

**同一条消息的两种归因**（她回：「今天有点忙」）：

- **增进关系：**「她真的在忙，还特意回我一句。」→ 内部但不成立，落到情境（外部、易变），我照常约下一次。
- **维持痛苦：**「她就是不想聊，忙只是借口。」→ 内部、稳定、可控，等于给她定了性，我退回不主动。

原句一个字没变，变的是我补上的那半句原因。

### 记忆：当下改写过去

**重构性记忆**：记忆持续被新信息修正。现在的满意决定我回忆里的版本——现在好，淡忘过去的不快；现在差，低估曾经的幸福。功能是维持对未来的乐观，代价是**学不到教训**：既然「已经在好转」，就不必改。

### 关系信念：宿命 vs 成长

**宿命信念**：两个人要么天生一对，要么根本不配。由此派生出六条有害观点：

| 有害信念            | 它暗示的结论            |
| --------------- | ----------------- |
| 分歧具有破坏性         | 有分歧＝不够爱          |
| 「读心术」很重要        | 需要我说明＝对方不够爱我     |
| 伴侣不可能改变         | 出了问题就一直是问题       |
| 每次性生活都应完美       | 不完美＝爱情有问题        |
| 男人和女人本质不同       | 了解异性不可能          |
| 美好关系自然而然产生      | 需要努力＝不是真爱        |

共同前提都是「真爱不需要努力、不需要说明」。**成长信念**则把好关系看成一起处理困难的结果。差别在摩擦出现时显形：持成长信念的人更投入、更相信伤害可修复，能平静讨论对方的缺点；持宿命信念的人充满敌意，**更愿意结束关系而不是修复它**——因为若问题是「性格不合」，努力根本无从谈起。

### 期望：我造出我预期的证据

四步闭环：**我预期 → 我按预期行事 → 对方感到被怎样对待 → 对方照同样方式回应 → 我看到反应，说「我早说了」。** 关键在最后一步：我不认为是我先动的手。

电话实验（Snyder et al., 1977）：男生以为对面是美女时会更热切、问得更多；女生不知道照片的事，只是回应一个热情的男生，录音里就被评为「更有魅力」。**她的魅力是他的热情引出的反应，他却记成她的属性。**

原始版只为**挑选**证据（验证性偏差），这一版是**制造**证据，所以连戳穿的口都没有。

**可操作的一句**：觉得被冷落时，先数自己给对了方几个能热络的入口，而不是先判断「她是不是不喜欢我」。这不是自责，是把不可控的猜测换成可控的动作。

### 自我知觉：想被赞美，也想被认对

**自我提升**＝渴望正面反馈；**自我验证**＝渴望与现有自我看法一致的反馈。自我评价高的人，两者指向同一批反馈；自我评价低的人会打架——赞美让他不安（对方随时可能看穿我），「你确实有问题」反而让他踏实，因为**可预测**。代价是旧自我概念被焊死。

## 三、印象管理

| 策略        | 想换到   | 备注                     |
| --------- | ----- | ---------------------- |
| **逢迎讨好**  | 喜欢    | 恋人最常用；不带操纵性时通常有效      |
| **自我推销**  | 尊重    | 职场常用；女性大力自荐有风险        |
| **恐吓**    | 服从    | 留下不良印象——服从不产生亲近       |
| **恳求**    | 帮助    | 留下不良印象——同情不是喜欢        |

**高自我监控者**善于按情境调整形象：朋友多，但共同点少、关系维持更短、对伴侣承诺更少；低自我监控者朋友少，但更像。这是描述，不是建议。

另一个特点：**我们对亲密伴侣经营形象，反而不如对外人卖力。**

## 四、我们到底有多了解伴侣

答案：**不如自己以为的准。** 我们高估了伴侣与自己的相似程度，因而觉得彼此理解，远超实际——而这些误解并不全是坏事，感知到的相似与理解越多，关系越满意。

判断准不准，取决于六件事（前三件最常被忽略）：

1. **了解**：相处越久确实越准，但会饱和。
2. **动机**：结婚几十年的夫妻并不比结婚一两年的更懂对方。时间只是容器，动机才是燃料。
3. **易理解性**：外向好读，神经质难读；约 20% 的人总是误导别人。
4. **知觉者能力**：情绪智力；女性平均更准，部分因为更努力去理解。
5. **威胁性知觉**：真相令人不安时，人反而会看不清。
6. **知觉者的影响**：最初不准的判断会被自己的行为变成真的。

## 三句可操作

1. **分事实与解释**：说出口前先问，「这句是看到的，还是我补的原因？」
2. **数入口**：觉得对方冷淡，先检查自己给了几个能回应的入口。
3. **看动机**：判断准不准，不取决于认识多久，而取决于我还想不想懂。

## 自测

1. 哈娜实验里两组看的录像相同，差异出在哪一步？为什么这一点比「偏见」更麻烦？
2. 「他迟到」的内部 + 稳定 + 可控，和外部 + 易变 + 不可控，分别导向什么反应？
3. 早餐例子里，丈夫和妻子各掌握了什么信息？它解释的是哪一种偏差？

5. 女生不知道自己被贴上「漂亮」的标签，为什么最后听起来真的更有魅力？
