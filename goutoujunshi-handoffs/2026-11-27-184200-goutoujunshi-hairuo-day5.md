## Key Patterns Discovered

- **“活人味” vs “人机味”的精确分水岭（Day 5 关键实战验证）**：
  - 用户与顾问都要严格禁用三类“人机味”词：
    1. **职场/研发黑话**：如 `校验 / 复核 / 同步本周情况 / leader`（应改为 `没留神 / 看一眼 / 领导找我聊了一嘴`）；
    2. **客服腔尾词与客套句**：如高频 `呢 / 呀 / 嗯嗯嗯 / ～ / 安心吃饭～ / 真细心呀`；
    3. **AI 网感套话**：如 `气场直接拉满 / 经典三连 / 属实被迫营业 / 太真实了 / 情绪价值到位`。
  - **高分活人示范**：用户实际发出的 18:30 三条大白话（`你声音好好听啊，话说你是不是在边吃饭边发语音啊` / `这个，处理bug多了，看见文件尾部多了一个.1，就能猜到是微信拦的了，外面套个壳就行` / `我还没吃呢，刚开完周会准备下班……算借你刚夸的吉言[旺柴]`），以及他原生的 `阿一古 / 行啊 / 抓紧 / 滴滴 / 可好吃啊 / [旺柴]`，立刻换来女方 6 连发。
- **体制内人情语境与“给方案本能”的避坑模式**：
  - 用户遇到女方忙碌带伤仍亲自去探望住院同事时，本能提出“点美团跑腿送过去”，略触碰熟人社会人情边界；好在用户不嘴硬辩论，一句“我只是单纯想你应该休息了”直接翻盘。后续凡遇人情往来或工作累，**先接感受、不替她做效率优化**。
- **看球不看己（防过度自我监控）**：
  - 上午四连发中突然插入“为什么我有时候加句号有时候不加，是概率学问题吗”，导致晾了女方刚抛的“还是不中咧”和“腿疼想练上肢”两个好球。发前 3 秒必须先检查**她刚抛的生活球接住没有**，不在对话框里公开剖析自己的标点/微动作。
- **自谦要归因于职业习惯，避免“仔细观察就知道了”的隐性居高临下**：
  - 解决 `.apk.1` 问题后，“处理 bug 多了顺眼看出来的”比“仔细观察一下就知道了”温暖且体贴得多。
